# ADR-0006 · App multiplataforma con React Native

- **Estado:** propuesta
- **Fuente:** [Diseño del MVP](https://claude.ai/artifact/8z2qFXRnnrty1u4cJAGH4R)

## Decisión
La app del alumno (credencial en el teléfono) y del escáner se hace con React Native.

## Nota
El MVP de constancias se usa desde la web, así que esta decisión espera al subsistema de acceso al plantel.
