# ADR-0007 · Servidor y simulador en Python con FastAPI

- **Estado:** aceptada
- **Fuente:** [Diseño del MVP](https://claude.ai/artifact/8z2qFXRnnrty1u4cJAGH4R)

## Decisión
El servidor y el simulador se escriben en Python. El servidor usa FastAPI.
El contrato OpenAPI se escribe primero, en el estándar, y el servidor se prueba contra él.
